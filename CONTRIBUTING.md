# Contributing to ascii-align

## Development

```bash
npm install
npm run check    # type-check
npm run build    # compile
npm test         # run tests
```

## Workflow

1. Fork the repo
2. Create a feature branch from `main`
3. Make changes, add tests
4. Run `npm test` and `npm run check`
5. Open a PR against `main`

## Bug reports

The most helpful bug reports include the exact ASCII input that fails and what the expected output should be.
